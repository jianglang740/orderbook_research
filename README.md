- 问题二：如何基于问题一的结果去研究短期流动性的情况和变动？

## 研究结果：

**这是目前我的解决方案，并基于以下内容做了代码实现：**

- 简而言之就是用REST 全量快照 + WebSocket 增量更新，然后在本地内存维护一个多线程的队列，而不是用 WebSocket 全量快照；

```
1. 订阅币安交易所的 WebSocket 增量流，开始缓存收到的消息（先不处理）
2. 用 REST 拉一份完整快照，记下 lastUpdateId = N 
3. 丢弃所有 u <= N 的缓存消息
4. 找到第一条满足 U <= N+1 <= u 的消息，从它开始处理
5. 此后每条消息：
     验证 pu == 上一条的 u（版本连续性）
     遍历 bids/asks 差量：qty=0 删除，qty>0 新增或覆盖
6. 如果发现版本号不连续，重新走步骤 1-4

更新规则：

qty = 0  → 删除该价格档位
qty > 0  → 新增或覆盖该价格档位的数量

```
